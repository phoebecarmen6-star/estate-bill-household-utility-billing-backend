## How to run the API
1. Install Java 17 and PostgreSQL.
2. Create an empty PostgreSQL database named `estate_bill`.
3. In `estate-bill-household-utility-billing/src/main/resources/application.properties`, set your PostgreSQL username and password.
4. From the folder `estate-bill-household-utility-billing`, run `./mvnw spring-boot:run` (Windows: `mvnw.cmd spring-boot:run`).
5. The API starts at `http://localhost:8080`.
